# PixlFlow - All-in-One Image Conversion & Optimizer

PixlFlow is a powerful, client-side media conversion suite designed for photographers, designers, and content creators. It allows users to convert, optimize, and enhance multiple images simultaneously directly within the browser, ensuring maximum privacy and speed.

## 🚀 Key Features

*   **Privacy First:** All processing happens locally in your browser. Your images never leave your device.
*   **Batch Processing:** Convert, resize, and enhance hundreds of images in seconds.
*   **Wide Format Support:** Supports JPG, PNG, WEBP, GIF, BMP, TIFF, SVG, ICO, HEIC, and RAW formats.
*   **Advanced Optimization:** Intelligent compression to reduce file sizes by up to 80% without visible quality loss.
*   **Comprehensive Controls:**
    *   **Resize:** By percentage or fixed dimensions.
    *   **Filters:** Grayscale, Sepia, Vintage, Blur, Sharpen, etc.
    *   **Rotation:** 90°, 180°, 270° adjustments.
    *   **Watermarking:** Add customizable text watermarks with position, color, and size controls.
    *   **Advanced Settings:** DPI resolution, Color Space (RGB, CMYK, Grayscale), and EXIF preservation.
*   **User Experience:**
    *   Dark/Light mode toggle.
    *   Real-time statistics (files processed, size reduction, time saved).
    *   Drag & Drop interface.
    *   Zip download for batch results.

## 🛠️ Installation & Setup

Since PixlFlow is a client-side web application, no complex backend setup is required.

1.  **Clone or Download** the repository.
2.  **Open** the project folder.
3.  **Launch** `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

That's it! The application is ready to use.

## 📖 Usage

1.  **Upload Images:** Drag and drop your images into the upload area or click "Select Images".
2.  **Configure Settings:**
    *   Select your desired **Output Format**.
    *   Adjust **Quality** and **Compression** levels.
    *   Apply any optional **Resizing**, **Rotation**, or **Filters**.
    *   Set up **Watermarking** if needed.
3.  **Process:** Click the "Process Images" button.
4.  **Download:** Once finished, you can download individual files or get them all in a single ZIP archive.

## 💻 Technologies Used

*   **HTML5 & CSS3:** For structure and modern, responsive styling.
*   **JavaScript (Vanilla):** Core logic for image processing.
*   **Libraries:**
    *   [JSZip](https://stuk.github.io/jszip/) - For generating ZIP files.
    *   [FileSaver.js](https://github.com/eligrey/FileSaver.js/) - For saving files locally.
    *   [FontAwesome](https://fontawesome.com/) - For UI icons.
